The standards that actually decide things

Not an exhaustive list — the ones that change a drawing, a tag number, a test or a sign-off. Editions move; confirm the current one before you cite it in a specification.

Reading order

Start with ISA-5.1 if you have to draw or read a P&ID; IEC 61131-3 if you have to program; IEC 61511 if anything you touch can hurt someone; API RP 551 if you have to install it; ISO 18674-1 if you have to watch a structure.
