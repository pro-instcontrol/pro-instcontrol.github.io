Applied Intelligence Processing

John G. Webster (chủ biên) · CRC Press, 1999

Companion to the Vietnamese translation of Chapter 84. The source prose is not repeated; the governing relations and reference data are summarised below.

Intelligent processing turns sensor data into decisions: multi-sensor fusion and Kalman/EKF/UKF state estimation (predict–update with gain K from P and R), time/frequency/time–frequency feature extraction, PCA whitening, classifiers (SVM, CNN), fuzzy rule bases and unsupervised anomaly detection (autoencoders, Mahalanobis distance, isolation forests). Practical reliability depends on representative training data, z-score normalisation, time synchronisation, concept-drift monitoring and an independent diagnostic path for safety-related measurements. Edge deployment adds int8 quantisation and latency/memory constraints.
