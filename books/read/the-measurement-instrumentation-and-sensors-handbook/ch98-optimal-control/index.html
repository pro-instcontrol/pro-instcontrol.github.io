98.1 Introduction

Optimal control maximizes (or minimizes) the value of a function chosen as the performance index or cost function of an operational control system. Optimal control theory, on the other hand, is the mathematics of finding parameters that cause the performance index to take an extreme value subject to system constraints.

Optimal control is applied in many disciplines: satellites and aerospace, aircraft and spacecraft, chemical engineering, communications engineering, robots and robotics, power systems, electric drives, computers and computer systems, and so on. In many applications simple interconnections of control devices and controllers do not provide the most economic operation, and optimal control offers the solution. Optimization is therefore useful in obtaining the best results from a known process. If the process is operating under steady-state conditions, optimization considers the process stationary and is concerned only with the operating points. When the process is stationary, the resulting optimum operating point can easily be maintained by setting the predetermined set points and precalculated control parameters. If the process changes from time to time, however, new optimum set points must be determined for each change.

The performance of a system is optimized for many reasons: improving quality, increasing production, decreasing waste, obtaining greater efficiency, maximizing safety, saving time and energy, and so on. In many optimization problems boundary conditions are imposed by the system itself for safety in operation, for the availability of minimum and maximum power, for limitations in storage capacity, for the capability of the operating machinery, for temperature, speed, force, acceleration — indeed, for any other hard physical reason.

Many different methods may be used to solve optimal control problems, depending on the nature of the problem. If the performance index and constraints can be formulated as linear algebraic functions of the controlled variables, linear programming may be the best route, and simplex methods provide a good way of solving the linear programming problem. If the equations describing the system are nonlinear, the solution may involve nonlinear techniques or the linearization of the problem over subregions. If the problem is to determine the largest value of a function of two or more variables, the steepest ascent (or descent) method — sometimes called hill climbing or the gradient method — may be used.

Hill-climbing methods are still popular and easy to understand. They are discussed briefly here, first, to lay a good foundation for a sound understanding of optimal control theory.

Figure 98.1 illustrates the hill-climbing technique in the region of the absolute minimum. The figure also shows a common pitfall in control theory: the local maxima and minima. As can be seen, the sign of the first derivative of the function changes as the derivative passes through the maximum point. The method commonly uses an initial estimated point at which the first derivative is considered (guessed) to be zero. That point is then used, in the direction of steepest ascent or descent as the case may be, to reach the next point, and so on until the absolute maximum or minimum is found without being trapped in a local extreme point. There are many different ways of finding maxima or minima by hill climbing, and Figure 98.2 illustrates some examples of implementation.

Apart from hill-climbing techniques, many new methods are available for modern optimal control problems involving hyperspaces (many variables) that are complex in nature and have stringent constraints. If a good mathematical model of the system is available, optimization methods may be used to find the optimum conditions on the model instead of seeking optimization on the actual process. The availability of the model thus determines the type of optimization method employed.

98.2 Cost Function

In designing optimal control systems, rules may be set for determining the control decisions, subject to certain constraints, such that some measure of deviation from an ideal case is minimized. That measure is usually provided by a selected performance index or cost function. The performance index is a function whose value indicates how well the actual performance of the system matches the desired performance. Appropriate selection of the performance index is important, since it determines the nature and complexity of the problem: whether the optimal control is linear or nonlinear, stationary or time-varying, depends on the selected performance index. The choice depends on system specifications, physical realizability, and the restrictions on the controls to be used. In general, choosing an appropriate performance index involves a compromise between a meaningful evaluation of system performance and the availability of feasible mathematical descriptions.

The performance index is selected by the engineer to make the system behave in a desired fashion. By definition, a system whose design minimizes the selected performance index is optimal. It is important to point out that a system optimal for one performance index may not be optimal under another. In practical systems, because of possible complexity and cost of implementation, it may be better to employ approximate optimal control laws that are not rigidly tied to a single performance index.

Before starting the optimization of any system it is necessary to formulate the system, having information on system parameters and describing equations, constraints, the class of allowable control vectors, and the selected performance indexes. The solution can then proceed by determining the optimal control vector u(k) within the class of allowable vectors. The control vector u(k) depends on such factors as the nature of the performance index, the constraints, the initial values of state and output, and the desired state as well as the desired outputs. If analytical solutions are impossible or too complicated, alternative computational solutions may be employed.

In simple cases the errors between the desired and actual responses can be chosen as the performance index to be minimized. Figure 98.3 depicts different descriptions of the error between actual and desired responses. The aim is to keep the errors as small as possible. The time integral of the error gives the severity of the error; however, since positive and negative errors cancel each other mathematically, absolute values must be used:

(98.1)IAE = ∫0T |e(t)| dt

In many cases it is better to use integral squared errors, which take large errors into account rather than ordinary ones:

(98.2)ISE = ∫0T e2(t) dt

Time-dependent functions can be used to capture errors occurring late in time rather than ordinary transients:

(98.3)ITAE = ∫0T t|e(t)| dt

and

(98.4)ITSE = ∫0T t e2(t) dt

Mean square error, MSE, is also commonly used, since a slight modification leads to the inclusion of statistical techniques and the analysis of random noise:

(98.5)MSE = limT→∞ (1/T) ∫0T e2(t) dt

Modern optimal control theory is developed within the state-space framework, and its performance indexes are more complex and comprehensive, as explained below.

Suppose the control command of a system is expressed in vectorial form as u and the state of the system is described by x (the Oxford English Dictionary defines state as condition with respect to circumstances, attributes, structure, form, phase or the like). Further suppose that the rate of change of state is a function of state x, control command u and time t:

(98.6)ẋ = f(x, u, t)    x(0) = x0 known

A control law u(x, t), or a control history u(t), is then determined such that a performance index — a scalar functional —

(98.7)J(u) = ∫0T g(x(t), u(t), t) dt

takes a minimum value out of all other possibilities while still satisfying Eq. 98.6. A boundary relationship x(T) = xf must also be met as a constraint.

A most common form of J(u) is minimum-time control, in which

(98.8)J(u) = ∫0T dt = T

Many other criteria are used as well, such as minimum fuel, minimum energy and other quadratic forms:

(98.9)J(u) = ∫0T u(t) dt
(98.10)J(u) = ∫0T u2(t) dt
(98.11)J(u) = ∫0T [q x2(t) + r u2(t)] dt

A general term for the continuous-time performance index that leads to optimal control is expressed as:

(98.12)J(u) = ∫0T g[x(t), u(t), t] dt

This performance index is minimized subject to the constraints above, together with x(t) being an admissible state, x(t) ∈ X(t), ∀t ∈ (t0, tf).

Slight variations of Eqs. 98.9 to 98.12 lead to the mathematics of the discrete-time, or digital, versions of optimal control.

98.3 Calculus of Variations

The calculus of variations is suitable for solving linear or nonlinear optimization problems with linear or nonlinear boundary conditions. Basically it is a collection of many different analytical methods, discussed differently from book to book. A typical approach, which leads to the more general and widely used modern theories, is introduced here.

Consider a dynamic system operating in the time interval t0 < t < tf

(98.13)ẋ(t) = f(x(t), u(t), t)    for t ∈ (t0, tf)

where the initial state x0 is given.

The system has n state variables and m control variables. The scalar function to be optimized is

(98.14)J = k[x(tf)] + ∫ L[x, u, t] dt

Define a scalar, for instance the Hamiltonian:

(98.15)H = H[x, u, λ, t] = L[x, u, t] + Σi λi fi

λ is known as the Lagrange multiplier. Also define a modified objective function:

(98.16)J = k[x(t1)] + ∫ H dt

The resulting solution is optimal when

(98.17)λ̇ = −∂H/∂x = −∂L/∂x − Σi λi ∂fi/∂x
(98.18)λ(tf) = ∂k/∂x
(98.19)∂H/∂u = ∂L/∂u + Σi λi ∂fi/∂u = 0,   t0 < t < tf

The solutions of Eqs. 98.17 and 98.19 in the above form are difficult to obtain. Nevertheless, more general theories can be developed from these ideas, such as Pontryagin's maximum principle.

An advance over the calculus of variations is Pontryagin's maximum principle, which offers easier solutions and extends the range of applicability to bounded control problems. In its simplest form the principle may be explained as follows.

Given the system

(98.20)ẋi = fi[x, u, t]

and an objective function

(98.21)J = Σi ki xi(tf)

The maximum principle states that if the control vector u is optimum, then the Hamiltonian

(98.21a)H = Σi pi fi

is also maximized with respect to the control vector u over the given intervals.

(98.21b)ṗi = −Σj (∂fj/∂xi) pj
(98.21c)pi(tf) = ki

where p is the adjoint or co-state vector, and

(98.21d)ẋi = ∂H/∂pi = fi[x, u, t]
(98.21e)∂H/∂xi = −ṗi

The initial values of the state vector x provide the remaining constants needed to solve these equations and determine an optimum control vector. The method also applies to systems with complex performance indexes.

Another extension of the calculus of variations is the Kalman filter. Kalman is essentially a general filtering technique that can be applied to problems such as optimal estimation, prediction, noise filtering, stochastic optimal control and the design of optimal controllers. The method has the advantage of providing estimates of variables in the presence of noise for both stationary and nonstationary processes. Most other types of noise can be treated by this method if they can be translated into Gaussian form. The technique can also be employed in systems with forcing disturbances and more than one noise source. In general, systems with quadratic objective functions or with uncorrelated Gaussian noise at the input are suitable for this technique.

One way of applying the Kalman filter to a nonlinear system is to find a good estimate of the system and use it to define a new set of linear state equations that approximates the system in linear form at a normal operating point. The filter can then be applied to the new set of linear equations.

Applications of the Kalman filter in instrumentation and measurement systems, and in other optimal control problems, are endless. It is easily programmed on digital computers.

98.4 Riccati Equation

Some models in optimization problems resemble the models of traditional control theory and practice. In these models the process and control variables are vector-valued and constrained by linear plant equations, and the cost functions take the form of quadratic costs. Such systems are termed linear quadratic, or LQ, systems. The theory and models of LQ systems are well developed in both the deterministic and the stochastic case.

Express a quadratic optimal control problem as

(98.22)x(k+1) = Ax(k) + Bu(k)    x(0) = x0

where

x(k) = state vector (n-vector)
u(k) = control vector (r-vector)
A = n × n nonsingular matrix
B = n × r matrix

The aim is to find the optimal control sequence u(0), u(1), …, u(N − 1) that minimizes the quadratic performance index

(98.23)J = ½x*(N)Sx(N) + ½ Σk=0N−1 [x*(k)Qx(k) + u*(k)Ru(k)]

where x* and u* are the transposes of the x and u matrices respectively, and

Q = n × n positive definite or positive semidefinite symmetric matrix
R = r × r positive definite or positive semidefinite symmetric matrix
S = n × n positive definite or positive semidefinite symmetric matrix

The matrices Q, S and R are selected to weight the relative importance of the performance measures caused by the state vectors x(k), the final state x(N) and the control vectors u(k) respectively, for k = 0, 1, 2, …, N − 1. The initial state of the system is arbitrary, but the final state x(N) may be fixed. If the final state is fixed, the term ½x*(N)Sx(N) may be removed from the performance index and the terminal state xf imposed. If the final state is not fixed, the term ½x*(N)Sx(N) represents the weight of the performance measure on the final state.

There are many different ways of solving the above equations, one of which makes use of Lagrange multipliers. With their aid the performance index may be modified as

(98.24)L = ½x*(N)Sx(N) + Σk {½x*(k)Qx(k) + ½u*(k)Ru(k) + λ*(k+1)[Ax(k) + Bu(k) − x(k+1)]}

It is known that minimization of the function L is equivalent to minimization of the performance index J under the same constraints.

In order to minimize, L must be differentiated with respect to the vectors x(k), u(k) and λ(k), and the results set to zero. Partial differentiation of L with respect to the variables gives

(98.25)∂L/∂x(k) = 0   →   Qx(k) + A*λ(k+1) − λ(k) = 0
(98.26)∂L/∂x(N) = 0   →   Sx(N) − λ(N) = 0
(98.27)∂L/∂u(k) = 0   →   Ru(k) − B*λ(k+1) = 0

and

(98.28)∂L/∂λ(k) = 0   →   Ax(k−1) + Bu(k−1) − x(k) = 0

A close inspection of the formulae above shows that the last equation is simply the state equation for k = 1, 2, 3, … N, and that the value of the Lagrange multiplier can be determined from Eq. 98.26. The Lagrange multiplier is often termed the covector or the adjoint vector.

Rewriting Eqs. 98.25 and 98.27,

(98.29)λ(k) = Qx(k) + A*λ(k+1)
(98.30)u(k) = −R−1B*λ(k+1)

the state Eq. 98.22 can be expressed as

(98.31)x(k+1) = Ax(k) − BR−1B*λ(k+1)

To obtain the solution of the minimization problem, Eqs. 98.29 and 98.31 must be solved simultaneously as a two-point boundary-value problem. The solutions of these two equations in this form, together with the optimal values of the state vector and the Lagrange multiplier vector, lead to the values of the control vector u(k) that optimize the open-loop control system. For closed-loop control systems, however, the Riccati transformations must be applied.

(98.32)u(k) = −K(k)x(k)

where K(k) is the r × n feedback matrix. The Riccati equation in feedback form can now be obtained by assuming that λ(k) is written as

(98.33)λ(k) = P(k)x(k)

where P(k) is an n × n matrix. Substituting Eq. 98.33 into 98.29 and 98.31 gives

(98.34)P(k)x(k) = Qx(k) + A*P(k+1)x(k+1)
(98.35)x(k+1) = Ax(k) − BR−1B*P(k+1)x(k+1)

In writing Eqs. 98.34 and 98.35 the Lagrange multiplier λ(k) has been eliminated. This is an important step in solving two-point boundary-value problems. By further manipulation it is possible to show that

(98.36)P(k) = Q + A*P(k+1)A − A*P(k+1)B[R + B*P(k+1)B]−1B*P(k+1)A

Equation 98.36 is known as the Riccati equation.

From Eqs. 98.26 and 98.33, writing λ(N) = Sx(N) = P(N)x(N) gives

(98.37)P(N) = S

Hence the Riccati equation can be solved backward from k = N to k = 0, starting from the known values of P(N).

The optimal control vector u(k) can now be calculated from Eqs. 98.29, 98.30 and 98.35:

(98.38)u(k) = −R−1B*λ(k+1) = −R−1B*(A*)−1[P(k) − Q]x(k) = −K(k)x(k)

where

(98.39)K(k) = −R−1B*(A*)−1[P(k) − Q]

It is worth noting that the optimal control vector may be obtained in slightly different forms by different manipulations of the above equations, such as

(98.40)u(k) = −R−1B*[P−1(k+1) + BR−1B*]−1Ax(k)

Equations 98.38 and 98.39 indicate that the optimal control law requires feedback of the state vector with time-varying gain K(k). Figure 98.4 illustrates the optimal control scheme of a system based on the quadratic performance index. In practical applications the time-varying K(k) is calculated before the process begins. Once the state matrix A, control matrix B and weighting matrices Q, R and S are known, the gain K(k) may be precomputed off-line for later use. The control vector u(k) at each stage can be determined immediately by premultiplying the state vector x(k) by the known gain K(k).

From the above equations the minimum value of the performance index can also be calculated. Using the initial values

(98.41)Jmin = ½x*(0)P(0)x(0)

The steady-state solutions of the Riccati equations are necessary when dealing with time-invariant (steady-state) optimal controls. There are many ways of obtaining steady-state Riccati solutions; an example is given below.

(98.42)P = Q + A*PA − A*PB(R + B*PB)−1B*PA

The steady-state value of K may be found as

(98.43)K = (R + B*PB)−1B*PA

and the optimal control law for steady-state operation may be expressed as

(98.44)u(k) = −(R + B*PB)−1B*PA x(k)

This section has been presented for discrete-time optimal control systems rather than continuous systems, because computers and microprocessors have recently come into widespread use as on-line and off-line control tools. Since the principles are the same, the solutions can easily be extended to continuous-time systems with minor modifications.

98.5 State Feedback Matrix

The state feedback method is another design technique that allows the designer to locate the poles of the system wherever they are needed. This approach is termed the pole-placement method, where pole refers to the poles of the closed-loop transfer function as in Fig. 98.5. The method assumes that the state variables are measurable and available for feedback. If the state is available the system is said to be deterministic: it is noise free and its parameters are fully known. If the state is not available, methods such as measurement feedback laws or state estimators may be selected.

In many applications, instead of the state variables it is more convenient to use state estimates coming from an observer or a Kalman filter. In this case three well-known methods are available: certainty equivalence, separation and dual control. Certainty equivalence has considerable advantages over the others because it leads to deterministic optimal control laws such as Pontryagin's principle, or to the conditional mean of the state such as the Kalman filter. It leads to a practical controller, which may be built as a filter and an optimal law in cascade.

State feedback controllers are relatively easy to implement. For example, in the pole-placement method the relationship of the feedback control u to the state x for linear systems is

(98.45)u(k) = −Kx(k)

In linear quadratic cases the gain K is time varying:

(98.46)u(k) = −K(k)x(k)

where K is the n × r feedback matrix. This is correct in at least two cases.

1. In linear systems with no noise, pole-placement controllers and an observer as the state estimator, the control algorithms for

x(k+1) = Ax(k) + Bu(k)
y(k) = Cx(k)

are

(98.47)x̂(k+1) = (A − GC)x̂(k) + Gy(k) + Bu(k)
(98.48)u(k) = Kx̂(k)

where the eigenvalues of (A − GC) and (A + BK) are chosen to meet the design specifications.

2. In linear systems influenced by Gaussian white noise, in which the control is optimal according to a quadratic criterion, the system

(98.49)x(k+1) = Ax(k) + Bu(k) + Gv(k)
(98.50)y(k) = Cx(k) + w(k)

has a control law of the form

(98.51)x̂(k+1|k) = Ax̂(k) + Bû(k)
(98.52)x̂(k+1) = Ax̂(k+1|k) + G(k+1)[y(k+1) − Cx̂(k+1|k)]
(98.53)û(k) = K(k)x̂(k)

where K(k) and G(k) are the optimal gains for the deterministic optimal controls and the Kalman filters respectively.

In practice not all the state variables are easily accessible, and in general only the outputs of the system are measurable. Therefore, when feedback from the state variables is required in a given design, the states must be observed from information contained in the output as well as in the input variables. The subsystem that performs this observation of the state variables from the measurements of inputs and outputs is called the state observer. Figure 98.6 shows the block diagram of such a system.

Suppose a state feedback gain K has been selected so that the eigenvalues of

(98.54)x(k+1) = Ax(k) + Bu(k)
(98.55)u(k) = −K(k)x(k) + r(k)

are located at λ1, λ2, … λn. Furthermore, assume that the gain G in the identity observer

(98.56)x̂(k+1) = (A − GC)x̂(k) + Bu(k) + Gy(k)

is chosen such that the eigenvalues of the observer are μ1, μ2, … μn.

Defining Terms

Calculus variations: a technique which can be used for solving linear or nonlinear optimization problems with boundary conditions.

Controllability: property of a control system such that a determined input takes every state variable from a desired initial state to a desired final state.

Controller: a subsystem that assists in achieving the desired output of a plant or process.

Cost function: a function whose value indicates how well the actual performance of the system matches the desired performance.

Covector: Lagrange multiplier.

Hill climbing: a method of determining absolute maxima or minima by using an initial guess point and the derivatives of the function.

Kalman filter: a procedure which provides optimal estimates of state.

Lagrange multiplier: a mathematical expression that modifies the performance index to give an optimal solution.

Linear quadratic equation: cost functions in quadratic form.

Linear system: a system that possesses the properties of superposition.

Optimal control: a control technique that maximizes or minimizes the cost function of a system.

Optimization: the procedure of obtaining maximum or minimum performance.

Performance index: cost function.

Pole-placement method: a design technique that makes use of the closed-loop properties of the system.

Riccati equation: a set of equations that transform control equations to lead to optimal solutions.

State equation: a set of simultaneous first-order differential equations with n variables leading to solutions of the state variables.

State-space model: a mathematical expression of a system consisting of simultaneous first-order differential equations and an output equation.

State variables: a set of linearly independent system variables such that, once their values are set, they determine the value of all system variables later in time.
