Control systems

W. Bolton · Newnes, 2002

Chapter 1 · 45 source pages · 77 figures · companion notes
Key terms. System — parts within a boundary giving outputs from inputs. · Open-loop — output does not affect the input. · Closed-loop — output is fed back and compared with the required value. · Negative feedback — feedback subtracted from the set value. · Comparison element — produces the error signal. · Correction element — acts on the process. · Sensor — gives a signal related to the measured variable.

This chapter gives a non-mathematical overview of control systems: the concept of a system and its block-diagram representation, how block diagrams describe open- and closed-loop systems, examples of the measurement, signal-processing and correction elements used, and finally the common structural pattern shared by a wide range of real control systems.

1.1 Introduction Giới thiệu

Automation describes the automatic operation or control of a process. Modern manufacturing uses automation increasingly — robotic production lines producing components with virtually no human intervention — and it is spreading into domestic and office appliances. Automation carries out operations in the required sequence and controls outputs to required values.

Key historical points in the development of automation:

  • Modern manufacturing began in 18th-century England with water wheels and steam engines.
  • Powered machinery in the early 1900s improved component accuracy, allowing identical batches.
  • Henry Ford developed the production line in 1909.
  • 1920s: theoretical principles of feedback control; automatic steering of ships and aircraft.
  • 1940s (WWII): radar tracking and gun control; Bode's 1945 paper on network analysis and feedback-amplifier design.
  • 1952: numerical control (NC) positioned tools from punched-tape instructions (open-loop).
  • 1948: the transistor → integrated circuits → 1970s microprocessors, making control cheap and widespread (washing machines, auto-focus cameras).

This book introduces the basic ideas of designing control systems; this chapter introduces the basic idea of a control system and the elements used.

1.2 Systems Hệ thống

A car gear box can be viewed as a system with an input and output shaft (Figure 1.1(a)); an amplifier is a system with an input signal and a related output signal (Figure 1.1(b)). Thus a system is like a closed box: we apply inputs and obtain outputs, the output being related to the input.

A system is an arrangement of parts within a boundary that provides an output from specified inputs (Figure 1.1(c)). The boundary separates the system from the environment; signals cross it as inputs and outputs. Engineers care more about inputs and outputs than internal detail.

In control we model a physical system as blocks with inputs, outputs and a mathematical relationship (Figures 1.2, 1.3). An operational amplifier is used by its known input–output relation without knowing its internals.

1.2.1 Block diagrams Sơ đồ khối

A block diagram shows a system element as a box with an input arrow and an output arrow (Figure 1.4(a)). Elements connect in series (1.4(b)). A summing junction adds/subtracts signals, marked + or − (1.4(c)). A take-off point taps a signal (1.4(d)). Figure 1.5 shows a central-heating system with negative feedback.

1.3 Control systems models Mô hình hệ thống điều khiển

There are two basic types (Figures 1.6, 1.7):

Open-loop Vòng hở

The output has no effect on the input. Advantages: simple, cheap, reliable. Disadvantage: no correction for disturbances. An electric fire selected at 1 kW or 2 kW holds a temperature set once and makes no further adjustment (Figure 1.6); opening a window is not compensated. Used for sequencing operations such as washing machines.

Closed-loop Vòng kín

A signal indicating the output state is fed back, compared with the required value, and used to modify the output to maintain it (Figure 1.7). Advantages: accurate; disadvantages: more complex, costlier, more failure-prone. A person with a thermometer adjusting the fire is a closed loop with negative feedback (Figure 1.8): the feedback is subtracted from the set value.

1.3.1 Basic elements of an open-loop control system Các phần tử cơ bản của hệ vòng hở

Three basic elements (Figure 1.9): control, correction and process. No correction is made for disturbances.

1.3.2 Basic elements of a closed-loop system Các phần tử cơ bản của hệ vòng kín

Figure 1.10 shows the general form. Forward-path elements are comparison, control law, correction and process.

Functions:

  • Comparison element: compares the required value with the measured value to give the error signal: error = reference − measured actual value.
  • Control-law element: decides the action for an error — on/off, proportional, integral, derivative. A differential amplifier combines comparison and control law.
  • Correction element (final control element): changes the process; the actuator supplies the power — e.g. a motor or cylinder (Figure 1.11).
  • Process: the system whose variable is controlled.
  • Measurement element: produces a signal related to the controlled variable, e.g. a temperature sensor.

Feedback path: a signal related to the actual condition is fed back to modify the input. Negative feedback (subtracted) is required for control; positive feedback adds to the input. Forward path: from the error signal to the output.

1.3.3 Discrete event control Điều khiển theo sự kiện rời rạc

Sequential control: actions determined by observed time-critical events. Filling a container: an empty sensor switches the flow on, a full sensor switches it off — a closed loop receiving feedback from two sensors (Figure 1.12).

1.4 Measurement elements Các phần tử đo lường

Common sensors in control-system measurement:

1.4.1 Potentiometer Potentiometer

A resistance element with a sliding contact. With constant supply voltage V, the output V₀ is a fraction of the input, depending on the ratio of resistances. If resistance is uniform, V₀ is proportional to slider displacement — measuring linear or angular position (Figure 1.13).

1.4.2 Strain-gauged element Phần tử strain-gauge

A strain gauge is a wire/foil/semiconductor strip whose resistance R changes when stretched: ΔR/R = G·ε, where G (gauge factor) is about 2.0 for metal gauges. Mounted on a cantilever it becomes a displacement sensor (Figure 1.14): bending stretches the upper gauge (R up) and compresses the lower (R down).

1.4.3 Linear variable differential transformer (LVDT) Máy biến áp vi phân từ tính tuyến tính

An LVDT has a primary and two series-opposed secondary coils. With the magnetic core central, the induced e.m.f.s cancel (zero output). Displacing the core makes one coil dominate, giving an output proportional to displacement (Figure 1.15). Ranges about ±2 mm to ±400 mm.

1.4.4 Optical encoders Bộ mã hóa quang

Encoders give a digital output from angular/linear displacement. Incremental encoders count pulses from a slotted disc (Figure 1.16). Absolute encoders output a binary word for each position (Figure 1.17).

1.4.5 Switches Công tắc

A mechanical switch detects the presence of an object — e.g. a limit switch closed when a workpiece arrives (Figure 1.18).

1.4.6 Tachogenerator Máy phát tốc

A coil in a magnetic field induces an alternating e.m.f. proportional to angular speed when rotated (Figure 1.19). Used to measure shaft speed.

1.4.7 Pressure sensors Cảm biến áp suất

A diaphragm deflects under a pressure difference (Figure 1.20). Its movement is monitored with strain gauges (Figure 1.21) or a piezo-electric crystal (Figure 1.22) — the crystal generates charge on compression but leaks, so it is not for static pressure.

1.4.8 Fluid flow Lưu lượng chất lỏng

By Bernoulli's equation, the pressure drop across a restriction is proportional to the square root of flow rate. The Venturi tube (Figure 1.23) and orifice plate (Figure 1.24) measure the pressure difference to infer flow. A turbine flowmeter (Figure 1.25) has a rotor whose speed is roughly proportional to flow; a magnet gives countable pulses.

1.4.9 Liquid level Mức chất lỏng

A float's position is directly related to liquid level; linked to a potentiometer slider it gives a level-related voltage (Figure 1.26).

1.4.10 Temperature sensors Cảm biến nhiệt độ

Many properties change with temperature: expansion, resistance, thermoelectric e.m.f., and current across semiconductor junctions. The bimetallic strip bends when heated (Figure 1.27). Thermistors decrease resistance non-linearly when hot (Figures 1.28, 1.29) — small and fast but non-linear. Thermocouples (Figure 1.30) give an e.m.f. between two junctions at different temperatures (Figure 1.31); a cold-junction compensation circuit (Figure 1.32) emulates 0 °C. The LM35 IC gives a linear 10 mV/°C output (Figure 1.33).

1.5 Signal processing Xử lý tín hiệu

The sensor or controller signal may need processing to suit the next element: amplification, analogue↔digital conversion, resistance→voltage, voltage→current, pressure→current, etc. For example, a thermocouple output of a few mV needs amplification and cold-junction compensation.

1.5.1 Resistance to voltage converter Đổi trở sang áp

A potential divider (Figure 1.34) with a thermistor and series resistor R gives an output across R: V_out = V·R/(R+R_t). The Wheatstone bridge is another example.

1.5.2 Protection Bảo vệ

A series resistor limits current and a fuse breaks the circuit on over-current (Figure 1.35). An optoisolator (Figure 1.36) uses an LED and phototransistor to fully isolate two circuits.

1.5.3 Analogue to digital conversion (ADC) Đổi tương tự sang số

An analogue signal (Figure 1.37(a)) varies continuously; a digital signal (1.37(b)) is in steps. Microprocessors need digital inputs, so an ADC is used. Stages: sampling (1.38(a)), a clock (1.38(b)), sampled pulses (1.38(c)), held samples (1.38(d)), then digital words (1.39). A 3-bit ADC divides the range into 8 levels (Figure 1.40); resolution = V_FS/2ⁿ.

1.5.4 Digital to analogue conversion (DAC) Đổi số sang tương tự

Microprocessor output is digital but most elements need analogue. A DAC takes a binary word and gives the equivalent analogue value (Figure 1.41); e.g. 7 V full-scale: 000→0 V, 111→7 V.

1.5.5 Amplifiers Bộ khuếch đại

The op-amp has inverting (−) and non-inverting (+) inputs and very high gain (~100 000). Figure 1.42 is the 741 pinout. The inverting amplifier (Figure 1.43): V_out/V_in = −R₂/R₁ (virtual earth). The differential amplifier (Figure 1.44) amplifies the difference of two inputs.

1.6 Correction elements Các phần tử hiệu chỉnh

1.6.1 Directional control valves Van điều hướng

A directional valve changes, stops or starts flow on an external signal. Each square is a position (Figure 1.45(a) two-position, (b) three-position). Flow paths (arrows) and shut-offs (terminated lines) are drawn inside; ports are outside at the rest position (Figure 1.46). Valves are described by ports/positions: 2/2, 3/2, 4/2, 5/3 (Figure 1.47). Actuation methods include push-button, lever, spring, pedal, roller, solenoid, pneumatic (Figure 1.48). Figure 1.49 shows a 3/2 solenoid valve with return spring.

Figures 1.50 and 1.51 show single- and double-acting cylinder control with solenoid valves.

1.6.2 Flow control valves Van điều khiển lưu lượng

A pneumatically actuated stem moves a plug in the flow path to change the gap (Figures 1.52, 1.53). Plug shape sets the characteristic: linear, equal-percentage, quick-opening (Figures 1.54, 1.55).

1.6.3 D.c. motors Động cơ DC

DC motors are widely used. Classified by winding connection: series (Figure 1.56(a), high starting torque), shunt (1.56(b), nearly constant speed), compound (1.56(c)), separately excited (1.56(d)). Torque–speed characteristics in Figure 1.57.

1.6.4 Stepper motor Động cơ bước

A stepper rotates in equal steps per input pulse — accurate positioning. Permanent-magnet (Figure 1.58, 90° steps) and variable-reluctance (Figure 1.59) types. The SAA1027 driver (Figure 1.60) sequences the stator coils.

1.7 Control systems Hệ thống điều khiển

The following examples illustrate closed-loop systems; despite different forms, they share the same basic structural elements.

1.7.1 Control of the speed of rotation of a motor shaft Điều khiển tốc độ trục động cơ

A potentiometer sets the required speed; a differential amplifier compares it with feedback from a tachogenerator and adjusts the motor via bevel gears (Figures 1.61, 1.62).

1.7.2 Control of the position of a tool Điều khiển vị trí dụng cụ

A stepper motor drives a belt to position a tool; a potentiometer measures position and feeds back to the microprocessor controller (ADC) (Figures 1.63, 1.64).

1.7.3 Power steering Trợ lái

When steering resistance exceeds a threshold, the system makes the wheels follow the steering wheel; feedback is mechanical from wheel position via a hydraulic valve (Figure 1.65).

1.7.4 Control of fuel pressure Điều khiển áp suất nhiên liệu

Engine management holds fuel pressure constant at the injectors via a diaphragm-and-ball regulator valve (Figures 1.66, 1.67). The spring sets the value; the diaphragm both compares and measures.

1.7.5 Antilock brakes Phanh chống bó cứng

ABS adjusts brake pressure so wheels do not lock: a wheel-speed sensor feeds back, the controller compares with stored data and operates the modulator valves (Figure 1.68).

1.7.6 Thickness control Điều khiển độ dày

An LVDT measures sheet-thickness error; the AC error is converted to DC, amplified and used to vary a DC motor's armature current, gearing down to move the upper roll (Figures 1.69, 1.70).

1.7.7 Control of liquid level Điều khiển mức chất lỏng

A float-operated pneumatic controller: level change moves the float, changing air pressure that adjusts the inflow valve (Figures 1.71, 1.72).

1.7.8 Robot gripper Cơ cấu kẹp robot

A gripper has fingers that pivot to clamp an object (Figure 1.73). Feedback of contact force is needed to grip with just enough force — a closed-loop system (Figure 1.74) using piezoelectric or strain-gauge sensors.

1.7.9 Machine tool control Điều khiển máy công cụ

Machine-tool systems control tool/workpiece position and operation. Memory supplies a program of required positions; continuous monitoring closes the loop on the work-table position (Figure 1.75).

1.7.10 An automatic drill Máy khoan tự động

A switch sensor detects the workpiece, the controller lowers and drives the drill; at full travel a second sensor reverses the motor (Figure 1.76). This is closed-loop discrete-event control.

1.7.11 Microprocessor-controlled systems Hệ điều khiển dùng vi xử lý

Many consumer products use a microprocessor controller: it compares the sensor input with the required value using a control law in memory and outputs to a correction element (Figure 1.77).
