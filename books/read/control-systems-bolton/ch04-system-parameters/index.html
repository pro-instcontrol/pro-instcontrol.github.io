System parameters

W. Bolton · Newnes, 2002

Chapter 4 · 13 source pages · 15 figures · companion notes
Key terms. Transient response — the response before the system reaches steady state. · Time constant τ — the time for the output to reach 0.63 of the steady-state value. · Damping ratio ζ — determines the amount of oscillation. · Overshoot — the amount by which the output exceeds the steady-state value at the first peak. · Settling time — the time taken for the oscillations to fall and remain within ±2% or ±5% of the steady state. · Pole — a root of the transfer-function denominator; it governs stability.

This chapter introduces the parameters used to specify a system's transient response — time constant, delay time, rise time, overshoot, subsidence ratio and settling time — for both first- and second-order systems, then considers the conditions for stability via the location of the poles on the s-plane.

4.1 Introduction Introduction

When a system is subject to, say, a unit step input it may give an output which eventually settles down to some steady state value. The response that it gives before settling down to this steady state is called its transient response. This chapter is about the parameters used to specify the transient response of systems and whether the transients lead to unstable systems.

For example, if we have a spring system (Figure 4.1) and suddenly apply a load to it, it has a transient response which results in it taking some time to reach its steady state value and also it is likely to overshoot the steady state value before it finally settles down. What factors can we change with the spring system in order to get it to respond more quickly to an input and also to minimise the overshooting? As another illustration, consider a control system used with an automatic machine to position a workpiece: we need to know how fast the system will respond and whether it will overshoot the required position — overshooting is undesirable in such a situation.

With the spring system, after some oscillations with ever-decreasing amplitude, the transients die away and the system settles down to a steady state value — the system is said to be stable. If, however, the oscillations continued with ever-increasing amplitude, then no steady state value would be reached and the system would be unstable. This chapter takes a brief look at the conditions for stability of systems.

4.2 First order systems First order systems

A first order system has a transfer function of the form:

(4.1)G(s) = k / (τs + 1)

where k is the steady state gain and τ the time constant. When a unit step input is applied, the output y is:

(4.2)y = k (1 − e^(−t/τ))

When t = τ then y = k(1 − e^(−1)) = 0.63k. Thus the time constant τ of a first order system subject to a step input is the time taken for the output to reach 0.63 of the steady state value.

The parameters used to specify the transient performance are:

Delay time Delay time

The delay time td is the time required for the output response to reach 50% of its steady state value. Since k is the final value:

(4.3)k/2 = k(1 − e^(−t_d/τ)) → t_d = τ ln 2

Rise time Rise time

The rise time tr is the time required for the output to rise from 10% to 90% of its steady state value (note: sometimes specified 0% to 100%). The time to reach 10% is:

(4.4)0.1k = k(1 − e^(−t_10/τ)) → t_10 = τ ln 10

The time to reach 90% is:

(4.5)0.9k = k(1 − e^(−t_90/τ)) → t_90 = τ ln 10 − τ ln 9

Hence the rise time is:

(4.6)t_r = t_90 − t_10 = τ ln 9

Example Example

Determine the delay time and the rise time for a first order system with the transfer function G(s) = 3/(2s+1). Comparison with k/(τs+1) gives a steady state gain of 3 and a time constant of 2 s. Thus the delay time is t_d = 2 ln 10 = 4.6 s; the rise time is t_r = 2 ln 9 = 4.4 s.

A mercury-in-glass thermometer acts as a first order system with temperature as input and mercury position as output. Initially at 0°C, it is suddenly placed in water at 100°C and reads 98°C after 80 s. Then θ = 100(1 − e^(−t/τ)); from 98 = 100(1 − e^(−80/τ)) we get τ = 49.7 s. (a) Time constant 49.7 s; (b) delay time t_d = 49.7 ln 10 = 114.4 s; (c) rise time t_r = 49.7 ln 9 = 109.2 s.

4.3 Second order systems Second order systems

A second order system has a transfer function of the form:

(4.7)G(s) = ωn² / (s² + 2ζωn s + ωn²)

The output for a unit step input depends on whether the damping factor ζ is less than, equal to or greater than 1 — the corresponding outcomes being underdamped, critically damped and overdamped (see Section 3.5). For the underdamped oscillations:

(4.8)y = k [ 1 − (e^(−ζωn t)/√(1−ζ²)) · sin(ωd t + φ) ]

with the damped natural frequency ωd = ωn√(1−ζ²). Figure 4.2 shows the step response of an under-damped system.

Rise time Rise time

The rise time tr is the time taken for the response to rise from 0 to the steady-state value yss — a quarter of a cycle, i.e. ωd·t_r = π/2. We reduce the rise time by increasing ωd:

(4.9)t_r = π / (2 ωd) = π / (2 ωn √(1−ζ²))

The rise time is sometimes specified as the time to rise from 10% to 90% of the steady state value.

Peak time Peak time

The peak time tp is the time taken for the response to rise from 0 to the first peak value — half a cycle, i.e. ωd·t_p = π:

(4.10)t_p = π / ωd = π / (ωn √(1−ζ²))

When ζ is 1 the peak time becomes infinite; at critical damping the steady state value is never reached but only approached asymptotically.

Overshoot Overshoot

The overshoot is the maximum amount by which the response overshoots the steady state value, often written as a percentage of the steady state value. At ωd·t = π the output exceeds the steady state by:

(4.11)overshoot = y_ss · e^(−ζπ/√(1−ζ²))

Expressed as a percentage of y_ss:

(4.12)%overshoot = e^(−ζπ/√(1−ζ²)) × 100%

The overshoot does not depend on the natural frequency but only on the damping factor. As ζ approaches 1 the percentage overshoot approaches zero. Table 4.1 gives values of the percentage overshoot for particular damping ratios.

Subsidence ratio Subsidence ratio

The subsidence ratio (or decrement) is the amplitude of the second overshoot divided by the amplitude of the first overshoot. At ωd·t = π and ωd·t = 3π:

(4.13)subsidence ratio = second / first = e^(−2πζ/√(1−ζ²))

Settling time Settling time

The settling time ts is a measure of the time taken for the oscillations to die away — the time for the response to fall within and remain within some specified percentage of the steady-state value. For the 2% settling time:

(4.14)t_s = 4 / (ζ ωn)

For the 5% settling time:

(4.15)t_s = 3 / (ζ ωn)

Number of oscillations to settling time Number of oscillations to settling time

The periodic time is 2π/ωd. In a settling time ts (2% criterion) the number of oscillations is:

(4.16)number of oscillations = (4/(ζωn)) / (2π/ωd) = 2ζ / √(1−ζ²)

For a rapid response (small rise time) the natural frequency must be large. Figure 4.3 shows the types of response to a unit step input of systems having the same damping factor of 0.2 but different natural angular frequencies — the response with ωn = 10 rad/s is much faster than that with ωn = 1 rad/s. The damping factor is typically in the range 0.4 to 0.8: smaller values give excessive overshoot, larger values render the system sluggish. Figure 4.4 shows the effect on the response of changing the damping factor when the natural angular frequency is unchanged.

Example Example

A second order system has a natural angular frequency of 2.0 rad/s and a damped frequency of 1.8 rad/s. (a) Since ωd = ωn√(1−ζ²), ζ = 0.44. (b) The 100% rise time is t_r = π/(2·1.8) = 0.87 s. (c) The percentage overshoot is exp(−0.44π/√(1−0.44²))×100% = 21%. (d) The 2% settling time is t_s = 4/(0.44·2.0) = 4.5 s. (e) The number of oscillations within the 2% settling time is 2·0.44/√(1−0.44²) = 1.3.

The feedback system shown in Figure 4.5 has a forward path K/[s(s+a)] and a feedback path 1. The closed loop transfer function is:

(4.17)G(s) = K / (s² + a s + K)

By comparison with the standard second-order form, ωn = √K and ζ = a/(2√K). Since ωd·t_r = π/2, t_r = π/(2ωn√(1−ζ²)) — the rise time decreases as K increases (faster response). The percentage overshoot = exp(−ζπ/√(1−ζ²)) increases as K increases. The 2% settling time t_s = 4/(ζωn) = 4/a — independent of the gain K.

4.4 Stability Stability

We define a stable system as one which, when given an input or a change in input, has transients which die away with time and leave the system in a steady state condition. The system is unstable if the transients do not die away but grow with time.

Consider a second order system G(s) = 1/[(s+1)(s+2)]. The values of s which make the transfer function infinite are termed the poles — here s = −1 and s = −2. A unit step input gives an output with terms e^(−t) and e^(−2t), both decaying to leave a steady state value of 0.5 — the system is stable. Now consider G(s) = 1/[(s−1)(s−2)] with poles s = +1 and +2, giving e^(+t) and e^(+2t) which grow — the system is unstable. Thus: a negative pole gives a transient which dies away (stable); a positive pole gives a transient which grows (unstable).

In general, for a second order system G(s) = ωn²/[(s+p1)(s+p2)], the roots (poles) are:

(4.18)p1 = −ζωn + ωn√(ζ²−1) , p2 = −ζωn − ωn√(ζ²−1)

With ζ > 1 we have real roots; with ζ < 1 we write j = √−1 and the roots become:

(4.19)p1 = −ζωn + j ωn√(1−ζ²) , p2 = −ζωn − j ωn√(1−ζ²)

We write the roots, and so poles, in the form a + jb; the jb part is an imaginary number. The same rule applies: if the a term is negative the system is stable, if positive it is unstable.

4.4.1 The s plane The s plane

We can plot the positions of the poles on a graph with the real part as the x-axis and the imaginary part as the y-axis — the s-plane. Figures 4.6–4.10 illustrate: real negative poles (stable, overdamped), real positive poles (unstable), complex left-half poles (stable, underdamped), complex right-half poles (unstable) and a double pole (critically damped). Figure 4.11 states that a system is stable if all its poles lie in the left half of the s-plane. Figure 4.12 shows that the more negative the real part the more rapidly the transient dies away, and the larger the imaginary part the higher the frequency of oscillation.

Example Example

Which systems are stable: (a) G(s) = 1/(s²+s+1) → poles −0.5 ± j0.866 (left half) → stable; (b) G(s) = 1/(s²−5s+4) → poles +4 and +1 (right half) → unstable; (c) G(s) = 1/(s²−2s+3) → poles +1 ± j√2 (right half) → unstable.
