This chapter uses the transfer function to find a system's time response to standard inputs (step, impulse, ramp). The method: multiply G(s) by the input in s-form, then read the time function from the Laplace table (or use partial fractions). It ends by applying this to first- and second-order systems.

3.1 Introduction Introduction

How does a system's output change when there is an input? Chapter 2 introduced the transfer function — the ratio of output to input as a function of s. This chapter uses it to determine how the output varies with time for particular inputs.

3.2 Inputs Inputs

Inputs commonly take a number of standard forms (Figure 3.1):

  • Step input: switches suddenly to a constant value at a particular time.
  • Impulse input: exists for a very brief time before dropping back to zero.
  • Ramp input: starts at a time and then increases at a constant rate.

As s-functions:

(3.1)Unit step: X(s) = 1/s
(3.2)Unit impulse: X(s) = 1
(3.3)Unit ramp: X(s) = 1/s²

If an input is multiplied by a constant, its Laplace transform is multiplied by the same constant (a 5 V step → 5/s; a 3 V/s ramp → 3/s²).

3.3 Determining outputs Determining outputs

The procedure:

  1. Determine the output as an s-function: Output(s) = G(s) × Input(s).
  2. Find the corresponding time function from a table of Laplace transforms (Table 3.1); sometimes the expression must first be rearranged into a tabulated form.

Useful properties: multiplying a Laplace transform by a constant multiplies the time function by the same constant; the sum of separate s-terms gives the sum of the corresponding time functions.

3.3.1 Partial fractions Partial fractions

Partial fractions convert a complex fraction into simpler fractions so it matches a tabulated form. Three basic types:

  • Denominator factors only of the form (s+a), (s+b), (s+c): one term per factor, A/(s+a) + B/(s+b) + …
  • Denominator has repeated (s+a)^n: one term for each power, A/(s+a) + B/(s+a)² + … + N/(s+a)^n.
  • Denominator has a non-factorising quadratic (as²+bs+c): (As+B)/(as²+bs+c) + C/(s+d).

Find the constants by choosing s-values that zero some terms, or by equating coefficients of powers of s. E.g. (s+4)/[(s+1)(s+2)] = 3/(s+1) − 2/(s+2); (3s+1)/(s+2)³ = 3/(s+2)² − 5/(s+2)³; (2s+1)/[(s²+s+1)(s+2)] = (s+1)/(s²+s+1) − 1/(s+2).

3.4 First order systems First order systems

A first-order system obeys τ·dy/dt + y = kx, with transfer function G(s) = k/(τs+1).

Unit impulse input (X(s)=1): Y(s) = k/(τs+1) = (k/τ)/(s+1/τ) → form 4. Output y = (k/τ)e^(−t/τ) — an exponential decay, maximum at t=0, then 0.37 after 1τ, 0.14 after 2τ, 0.05 after 3τ (Figure 3.2).

Unit step input (X(s)=1/s): Y(s) = k/[s(τs+1)] → form 5. Output y = k(1−e^(−t/τ)) — 0.63k after 1τ, 0.86k after 2τ, 0.95k after 3τ, steady value k after 4τ (Figure 3.3).

Example: an RC circuit has G(s)=1/(RCs+1); a 3 V impulse → Vc = (3/RC)e^(−t/RC). A thermocouple with G(s)=30×10⁻⁶/(10s+1) suddenly immersed in 100°C water (step 100/s) → V = 30×10⁻⁴(1−e^(−0.1t)).

3.5 Second order systems Second order systems

The equation is d²y/dt² + 2ζωn·dy/dt + ωn²y = kωn²x, transfer function G(s) = kωn²/(s²+2ζωn s+ωn²). For a unit step input, the damping ratio ζ gives three response forms:

  • ζ > 1 (overdamped): two distinct real roots, output decays without oscillation, approaching k.
  • ζ = 1 (critically damped): two equal real roots, output y = k[1 − e^(−ωn t)(1+ωn t)], no oscillation.
  • ζ < 1 (underdamped): complex roots, output oscillates with damped angular frequency ωd = ωn√(1−ζ²), approaching k.

Example: G(s)=1/(s²+8s+16)=1/[(s+4)²] → repeated root −4 → critically damped. The system dy/dt+5dy/dt+6y=x → G(s)=1/[(s+3)(s+2)] → two real roots → overdamped; by partial fractions y = 1/6 + (1/3)e^(−3t) − (1/2)e^(−2t).
